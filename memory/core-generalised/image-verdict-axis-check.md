On a character pack the operator judges the WHOLE character, and the body (proportions, the intended figure) is
what they notice first. "Those are two different people" meant the dressed images had an average body, not a
different face.

**Why:** 2026-10-04, a character image pack. I built a face strip, decided the face drifted, and launched a face-swap stage.
Operator: *"i meant different as in body different. you expect to see the [character]'s figure and you get an ordinary one. it's not face. it's the body"*. The face-swap run was wasted box time.

**How to apply:** when a verdict names no axis, compare the canonical against the items on body shape AND face side
by side before choosing a fix; if still unclear, ask which in one line. Related: [[judge-generated-images-at-full-size]],
a related project note.
