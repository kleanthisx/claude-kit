*(Written as requirements, not prohibitions — see [[instruction-decay-evidence]].)*

**Anything framed as research runs all six:**

1. **Write the numbered question list before fetching anything.** Each question carries its expected answer shape. This is what makes "is it covered?" answerable afterwards. Where the space can't be enumerated, enumeration is the first job.
2. **Produce rows before prose.** The artifact is {claim → source → locator}, one row each. Synthesise afterwards, from rows that already carry sources.
3. **Ship only claims that carry a source locator.** Where a claim has no page to point at, remove it and say the question is unanswered.
4. **Record negative results.** "Searched A, B, C for T — nothing found" is a finding, and it's the mechanism that lets a check terminate honestly instead of at boredom. A scan that only ever says *found another* is a sampler with a confident voice.
5. **Agree the termination rule up front.** Every question sourced-or-recorded-as-not-found, or a stated budget spent with the gaps named aloud. Report as "ran X → output Y" or "not verified: Z".
6. **Fetch, extract, cite.** Where something comes from my own recall rather than a fetched page, label it a hypothesis to go check.

**Why:** 2026-08-11. Reinforced by the ad-blocker story: two programmer friends had Claude security-check a Chrome extension they'd built; every "check again" surfaced another vulnerability, because the first pass reported completion it had no basis for. They returned to uBlock Origin and cut their AI usage. What drove them off wasn't that Claude was wrong — it was that it was wrong *and sounded finished*. Same day: asked "how do the scholars solve it?", I answered from memory with a list of unsourced names, one turn after writing rule 6 down.

**How to apply:** Run all six, in order, on anything called research. See [[coverage-is-sampling-not-headcount]], [[provenance-or-nothing]], [[report-verifiable-only]].
