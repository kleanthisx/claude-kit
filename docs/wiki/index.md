# claude-kit wiki

Project spoke for `claude-kit` (the packaged install: hooks, skills, doctrine, memory, tests).
Follows `projects/wiki/WIKI-STANDARD.md`. Facts true for this project only live here; facts
true across ≥2 projects belong in the hub at `projects/wiki/` and should be linked from here,
not copied.

Wiki created 2026-09-16 (first session for this project's wiki — did not exist before today).

## Pages
- **[NEXT.md](NEXT.md)** — start here. Current open items and blockers.
- **[log.md](log.md)** — short, newest-on-top action log, one line per entry.
- **[ACTION-LOG.md](ACTION-LOG.md)** — full narrative log: one unit per decision point, with the
  options on the table, what was checked, the numbers, the decision, the test run, and the files
  touched. Read this when the question is "why is this default what it is?"
- **[decisions.md](decisions.md)** — durable decisions, one line each, with a
  PROVEN ✓ / DISCARDED ✗ / STANDING ⚖ / OPEN ? marker.
